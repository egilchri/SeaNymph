# SeaNymph Compass Deviation Table

**File:** raw/Compass Deviation Table and Reference - Compass Deviation Table and Reference.pdf
**Origin:** Boat-specific measured deviation table for SeaNymph's compass

## Summary

A one-page PDF containing SeaNymph's actual compass deviation table — measured data for this specific boat, not a generic reference. Twelve entries at 30° intervals covering the full circle. This is primary boat data.

## Key Takeaways

- Maximum easterly deviation: **9°E at 330° magnetic**
- Maximum westerly deviation: **8°W at 180° magnetic**
- Zero deviation: **090° magnetic**
- Pattern: easterly deviation on N/NW headings; westerly on S/SE headings
- Deviation is significant enough to matter in fog navigation (up to 9° uncorrected = ~0.8 nm off track per 5 nm sailed)

## Contradictions / Surprises

> This is real measured data for SeaNymph — treat it as authoritative until the compass is re-swung. No contradictions with existing wiki content (navigation-apps.md mentioned TVMDC correction but had no boat-specific deviation values).
