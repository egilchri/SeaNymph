# Yamaha F2.5 Outboard — Specs and Maintenance Notes

**Type:** AI research report with owner annotation  
**File:** raw/yamaha_outboard.md

## Summary

Specs and usage notes for the Yamaha F2.5 4-stroke portable outboard, with Edgar's annotation confirming he has the **short shaft model (F2.5SMHB)**. This is the dinghy motor for SeaNymph's Zodiac Cadet 240.

## Key Takeaways

- **Model: Yamaha F2.5SMHB** — 15-inch short shaft, confirmed by owner
- **Engine:** 72cc single-cylinder 4-stroke OHV, TCI ignition
- **Output:** 2.5 HP at 5500 RPM (full throttle range 5250–5750 RPM)
- **Weight:** ~37–40 lbs
- **Fuel:** Internal tank, 87 octane, ~0.35 L capacity; run carb dry with fuel shutoff for storage
- **Cooling:** Water-cooled with thermostat
- **Start:** Manual recoil with choke lever
- **Shifting:** Forward and Neutral only; 360° steering provides reverse thrust (no true reverse gear)
- **Storage:** Can be stored on its side (tiller-side down) — oil-retention system prevents leaks
- **Oil check:** Sight glass on engine
- **Warranty:** 3-year limited

The existing [[dinghy]] page comparison table listed Yamaha F2.5 weight as 37 lbs; this source says 37–40 lbs (consistent). The key new fact is the confirmed model variant (SMHB = short shaft). Motor is within the Zodiac Cadet 240's 4 HP plate limit.
